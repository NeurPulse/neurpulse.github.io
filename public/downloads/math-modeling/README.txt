数学建模零基础学习示例

对应笔记：https://neurpulse.github.io/notes/#category-2
学习地图：https://neurpulse.github.io/notes/mathematical-modeling-roadmap/

使用 Python 3.11，解压后进入当前文件夹。建议创建独立虚拟环境，
安装依赖：python -m pip install -r requirements.txt
先运行：python mathematical-modeling-roadmap.py
其他示例：python 对应的英文文件名.py

图形示例会打开图窗。案例使用明确生成的教学数据或内置数据，
无需额外 CSV、联网下载数据或安装 PyTorch。合成结果不代表真实赛题复现。
固定随机种子有助于复现，浮点值和优化结果仍可能随环境略有差异。

requirements.txt 记录实际验证环境，不表示这些版本是最新版本。
每个脚本对应正文完整案例，阅读公式、假设与结果解释后再运行。
