> 《数据科学导引》系列笔记 · 学习地图
>
> 当前进度：全书十五章详细笔记已完成，可按学习地图顺序复习，也可按具体问题反查。

## 学习目标

这份地图回答三个问题：全书讲了什么，各章之间有什么依赖，面对一个具体问题时应该回到哪一章。它不是用目录代替阅读，而是帮助我们在学习细节之前先建立整体框架。

本书的核心不是孤立地介绍算法，而是展示一条完整链路：**把现实对象表示为数据，为数据建立模型，用算法求解，再评估结果能否支持实际任务。**

## 一条主线看懂全书

可以把数据科学项目压缩成六个环节：

1. **问题**：明确要解释、预测、分组、排序还是决策。
2. **数据**：明确观察单位、特征、标签、数据类型与采集过程。
3. **表示**：通过编码、清洗、标准化、降维或特征选择，把数据变成模型可处理的形式。
4. **模型**：描述输入、输出、变量关系以及不确定性。
5. **算法与评估**：在训练数据上求解，在未参与训练的数据上检查泛化效果。
6. **应用与计算**：把模型用于文本、网络或行业问题，必要时借助分布式系统扩大处理规模。

因此，“换一个更复杂的模型”只是其中一个局部选择。数据表示错误、评估泄漏或问题定义错误，都无法靠复杂模型自动修复。

## 推荐阅读顺序

### 第一阶段：建立流程与数据意识

阅读第 1—2 章，同时查阅附录 A、B、D、E。目标是能区分样本、特征、标签、距离、训练集和测试集，并理解预处理为什么会改变模型结果。

可配合已有笔记：

- [必备数学与 Python 基础](/notes/mathematical-modeling-foundations/)
- [数据预处理与插值](/notes/mathematical-modeling-data-preprocessing/)
- [机器学习流程与 KNN](/notes/mathematical-modeling-ml-sklearn-knn/)

### 第二阶段：掌握基本预测与发现任务

阅读第 3—7 章。先分清回归、分类、聚类和关联规则，再比较同一任务中不同模型的假设、复杂度与适用条件。第 5 章集成模型放在基本分类器之后，第 7 章关联规则不要与分类规则混为一谈。

可配合已有笔记：

- [回归与曲线拟合](/notes/mathematical-modeling-regression/)
- [线性判别与支持向量机](/notes/mathematical-modeling-ml-lda-svm/)
- [树模型与集成学习](/notes/mathematical-modeling-ml-tree-ensemble/)
- [聚类算法](/notes/mathematical-modeling-ml-clustering/)

### 第三阶段：理解表示、隐变量与依赖关系

阅读第 8—11 章。降维和特征选择都在减少输入维数，但前者通常构造新表示，后者保留原始特征的子集。EM 与概率图模型则把关注点推进到“哪些量没有直接观察到”和“变量之间怎样依赖”。

可配合已有笔记：[主成分分析与降维](/notes/mathematical-modeling-pca/)。

### 第四阶段：进入复杂数据与大规模计算

阅读第 12—15 章。文本和网络要求先理解数据结构，深度学习要求先理解神经网络与优化，分布式计算则要求把算法进一步拆成可并行执行的存储和计算任务。

可配合已有笔记：

## 按问题选择章节

| 当前问题 | 优先阅读 | 先问清楚什么 |
|---|---|---|
| 数据无法直接输入模型 | 第 2 章 | 缺失、类型、量纲和异常分别是什么？ |
| 预测连续数值 | 第 3 章 | 标签是什么，误差怎样衡量？ |
| 预测离散类别 | 第 4—5 章 | 类别是否平衡，错误代价是否相同？ |
| 没有标签，希望分组 | 第 6 章 | “相似”由哪种距离或结构定义？ |
| 发现项目共现规律 | 第 7 章 | 支持度、置信度和实际意义是否一致？ |
| 特征太多或可视化困难 | 第 8—9 章 | 要构造新特征，还是保留原特征？ |
| 存在隐类别或序列依赖 | 第 10—11 章 | 隐变量是什么，依赖假设是什么？ |
| 处理文章、评论或文档 | 第 12 章 | 文本如何表示，任务是主题还是情感？ |
| 处理关系与连接 | 第 13 章 | 节点、边、方向和权重分别是什么？ |
| 学习复杂层次表示 | 第 14 章 | 数据规模、结构先验和计算成本是否合适？ |
| 数据或计算超过单机能力 | 第 15 章 | 瓶颈究竟是存储、计算、通信还是算法？ |

## 每章应留下什么

为了把“看过”变成“会用”，每章笔记都尽量留下四类结果：

1. **概念关系**：这一章解决什么问题，与前后章节怎样连接。
2. **最小例子**：能手算或用小数据走通核心机制，而不只抄定义。
3. **可验证实现**：代码输入、输出和评价过程能够对应正文。
4. **边界与误区**：说明方法什么时候不适用，以及最容易混淆的概念。

复习时可以先看学习地图，再进入单章笔记；做题或项目时则按任务反查章节，不必每次都从第一页顺序重读。

## 复习卡片

- **全书主线**：问题 → 数据 → 表示 → 模型 → 算法与评估 → 应用与计算。
- **监督学习**：第 3—5 章，依赖带标签样本。
- **无监督学习**：第 6—7 章，关注分组或共现结构。
- **表示学习工具**：第 8—9 章，降维不同于特征选择。
- **隐变量与依赖**：第 10—11 章。
- **复杂数据与系统**：第 12—15 章。
- **最先补充的附录**：概率、矩阵、距离与模型评估。
