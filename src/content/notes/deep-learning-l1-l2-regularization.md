## 1. 正则化是什么

### 1.1 回顾过拟合

过拟合：训练集上表现好，验证集上表现差。原因有训练数据太少、训练时间太长、**模型太复杂**。

### 1.2 正则化的思路

**正则化（Regularization）= 在损失函数中加入惩罚项，限制模型复杂度。**

训练过程中不仅要把数据拟合好，还要为"模型太复杂"付出代价。模型被迫在"拟合得准"和"保持简单"之间取得平衡。

---

## 2. 奥卡姆剃刀：正则化的哲学根基

> "如无必要，勿增实体。" —— 14 世纪修士威廉·奥卡姆

| 案例 | 复杂理论 | 简单理论 | 谁的准确度高？ |
|------|---------|---------|-------------|
| 天文学 | 托勒密地心说（80+ 个本轮均轮） | 哥白尼日心说（7 个圆形轨道） | 简单的那个 |

**两个模型都能解释同样的现象 → 更简单的那个更接近本质规律。**

深度学习中的正则化，就是奥卡姆剃刀的数学化实现。

## 3. L1 正则化（Lasso）

### 3.1 公式

在原始损失函数上加入所有参数绝对值之和：

$$
\text{Loss}_{L1} = \text{Loss}(\theta) + \lambda \sum_i |\theta_i|
$$

### 3.2 惩罚项如何工作

- 新梯度 = 原始梯度 + 正则项梯度
- $|x|$ 的导数：$x>0$ 时为 $+1$，$x<0$ 时为 $-1$
- 每次参数更新时，所有参数往 0 的方向**匀速**缩减

### 3.3 效果

**参数会直接变成 0** → 产生**稀疏模型**。

- 权重为 0 意味着对应特征被完全忽略
- 等价于自动做了**特征选择**

### 3.4 $\lambda$ 怎么设

| 场景 | $\lambda$ 调整 |
|------|---------------|
| 数据量少 | 增大（更易过拟合，需更强约束） |
| 模型复杂 | 增大 |
| 特征多 | 增大 |
| 一般初始值 | $10^{-3}$ 或 $10^{-4}$ |

$\lambda$ 过大 → 欠拟合；$\lambda$ 过小 → 正则化无效。

## 4. L2 正则化（Ridge / Weight Decay）

### 4.1 公式

$$
\text{Loss}_{L2} = \text{Loss}(\theta) + \lambda \sum_i \theta_i^2
$$

### 4.2 惩罚项如何工作

- $x^2$ 的导数 = $2x$
- 参数离 0 越远，梯度越大（"推回"力度越强）
- 参数越接近 0，梯度越小（"推回"力度越弱）

### 4.3 效果

**参数会变小但不会等于 0** → 产生**平滑模型**。

所有参数被均匀地往 0 的方向压缩，但不消失。避免模型过度依赖某些特征，同时保留所有特征的贡献。

---

## 5. L1 vs L2 — 核心区别

| | L1 | L2 |
|------|-----|------|
| 惩罚项 | $\sum \vert\theta_i\vert$ | $\sum \theta_i^2$ |
| 导数 | $\pm 1$（常数） | $2\theta$（与参数值成正比） |
| 参数最终状态 | 很多变为 **0**（稀疏） | 变小但 **不为 0**（平滑） |
| 相当于 | 自动特征选择 | 权重衰减（Weight Decay） |
| 使用频率 | 较少 | **默认选择** |

### 为什么 L1 产生稀疏解而 L2 不产生？

```
L1：梯度恒为 ±1  → 不管参数多小，缩减速度不变 → 直接压到 0
L2：梯度 = 2θ   → 参数越小梯度越小 → 无限逼近 0 但永不等于 0
```

L2 像一个逐渐变软的海绵垫，越靠近 0 阻力越小，永远到不了 0。L1 像一个恒力弹簧，匀速拉到 0。

> 一般情况下**默认使用 L2 正则化**，实际中 L1 使用较少。

## 6. PyTorch 实现

### 6.1 手动加入 L2 正则化

```python
l2_norm = sum(param.pow(2).sum() for param in model.parameters())
loss = criterion(outputs, labels) + 1e-4 * l2_norm
```

### 6.2 更简单的方式：优化器内置 Weight Decay

PyTorch 的优化器直接支持 L2 正则化，无需手动修改 loss：

```python
optimizer = optim.SGD(model.parameters(), lr=0.01, weight_decay=1e-4)
```

`weight_decay` 就是对所有参数施加 L2 正则化的系数 $\lambda$，框架自动在参数更新时做"衰减"。

## 7. 总结

```
过拟合 → 模型太复杂 → 需要约束 → 正则化

正则化 = 损失函数 + 惩罚项
    ├── L1：λ·Σ|θ|  → 参数可以变成 0（稀疏，特征选择）
    └── L2：λ·Σθ²  → 参数变小但不为 0（平滑，权重衰减）

奥卡姆剃刀：能解释同样现象时，选最简单的那个。
正则化就是剃刀的数学化实现 — 逼着模型在"准确"和"简单"之间找到最优平衡。

实践：
    默认用 L2（weight_decay=1e-4）
    L1 用于需要自动特征选择的场景
    两者也可以组合使用（Elastic Net）
```
